# ปฏิทินเวรของฉัน

เว็บแอป Google Apps Script สำหรับลงเวรรายวันของตัวเอง และคำนวณรายได้สุทธิ

![หน้าหลัก](docs/preview-desktop.png)

## ความสามารถ

- ลงเวรรายวัน: บด 1–4, ชบด 1–4, ช 1–4, E 1–4, M 1–4, ออกหน่วย, ลา
- 1 วันลงได้หลายเวร (แถวละ 1 อย่าง) เช่น บด 3 + M 1
- เลือกก่อน แล้วกด **ตกลง** เพื่อบันทึก
- วันหยุดราชการดึงจากปฏิทินวันหยุดไทยของ Google อัปเดตอัตโนมัติทุกวันที่ 1 ของเดือน
- สรุปรายได้รายเดือน / ทั้งปี พร้อมหักภาษีและประกันสังคม

## การคิดเงิน (ค่าเริ่มต้น แก้ได้ที่ปุ่ม "ค่าเวร")

| รายการ | คิดอย่างไร |
|---|---|
| วันทำการ (จ–ศ ที่ไม่ใช่วันหยุดราชการ และไม่ได้ลา) | 1,200 / วัน |
| บด | 1,200 × 2 |
| ชบด | 1,200 × 3 |
| ช | 1,200 |
| ออกหน่วย | 1,200 |
| E | 800 |
| M | 400 |
| หักภาษี | 10% ของยอดรวม |
| ประกันสังคม | 850 / เดือน (เฉพาะเดือนที่มีรายได้) |

## ติดตั้ง

1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script**
2. วางโค้ด `Code.gs` และสร้างไฟล์ HTML ชื่อ `Index` แล้ววาง `Index.html`
3. เลือกฟังก์ชัน `setupMonthlyHolidaySync` แล้วกด **Run** หนึ่งครั้ง (อนุญาตสิทธิ์)
4. **Deploy → New deployment → Web app** (Execute as: Me)

อัปเดตโค้ดครั้งต่อไป: **Deploy → Manage deployments → ✏️ → New version**

## ชีตที่ระบบสร้างให้

| ชีต | เก็บอะไร |
|---|---|
| Shifts | วันที่, รหัสเวร (คั่นด้วย `,`), หมายเหตุ |
| Holidays | วันหยุดราชการ (`auto` / `manual` / `removed`) |
| Settings | อัตราค่าเวร, ภาษี, ประกันสังคม |
| Log | ประวัติการแก้ไข |
